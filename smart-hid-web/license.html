LICENSE PAYLOAD

授权载荷

License 是云端签名后的结构化载荷。主绑 ESP32 Device ID，ControlHub 用内嵌公钥本地验签。

  • device_id — 主绑定对象（ESP32 Device ID）
  • features — 授权功能集
  • valid_from / expires_at — 有效期
  • signature — 云端签名，本地离线校验

  "license_id": "LIC-2026-000123",
  "account_id": "ACC-...",
  "plan_id": "PLAN-DEVICE-1Y",
  "device_id": "HID-A1B2C3D4",
  "issued_at": "2026-08-11T10:00:00Z",
  "valid_from": "2026-08-11T00:00:00Z",
  "expires_at": "2027-08-11T00:00:00Z",
  "features": ["keyboard", "mouse", "system"],
  "license_version": 1,
  "signature": "MEUCIQD...（云端签名）"
}
FAQ

常见问题

断网了还能控制吗？

能。授权校验在 ControlHub 本地完成，License 验签通过后不依赖互联网。这是 V1 明确的成功标准：无云环境下，本地有效 License 可以继续控制。

一份授权能用在多台设备上吗？

不能。授权以设备为单位，主绑 ESP32 Device ID。激活时选定 Device 即占用该授权（UNUSED → 已绑定）。需要多台设备分别授权。

试用期间功能会被阉割吗？

不会。试用与付费的键鼠能力完全一致——键盘、鼠标、HTTP API、本地 MQTT 全部可用。区别只在累计有效控制时间：试用有时间上限，付费没有。

"累计有效控制时间"怎么算？

从第一条成功 HID Command 开始计时，无操作不消耗，配置/状态/诊断查询也不消耗。即"用才扣，不用不扣"。具体总体验时长不在 UI 和协议中写死。

授权过期后设备还能用吗？

授权过期后，Trial 模式仍可继续（按累计时间限制），设备本身不受锁死。续费后会获得新的有效 License。

小程序需要付费/登录吗？

不需要。BLE Toolkit+ 是开源个人小程序，不做会员、支付、订单、License。授权完全在 Smart HID Web / Cloud 与 ControlHub 之间完成。
