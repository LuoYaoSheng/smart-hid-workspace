目标电脑
无需装驱动
  • 目标电脑零侵入——它看到的就是一把普通 USB 键盘和鼠标，无需安装任何控制端或专用驱动。

CAPABILITIES

V1 键鼠能力

覆盖键鼠自动化的核心动作。V1 明确不做任意文本输入、宏脚本、Shell、远程桌面与截屏。

⌨️

键盘 Keyboard

  • tap — 单键敲击
  • hotkey — 组合键（如 Ctrl+C）
  • key_down / key_up — 按住 / 松开（带 lease）
🖱️

鼠标 Mouse

  • move — 相对移动
  • click — 单/双击
  • button_down / button_up — 按住 / 松开
  • wheel — 滚轮
🖥️

网页模拟键鼠

  • ControlHub 内置 /demo.html 演示台
  • 另一台电脑浏览器可视化键盘 + 触控板遥控
  • WebSocket 实时事件流，多端可观战
  • 实时延迟与执行计数，一键释放急停
🛡️

系统 System

  • release_all — 释放所有按住的键鼠
  • 会话级安全保障，异常时一键归零
🔐

可靠性

  • 每命令带 request_id，环形去重
  • ttl_ms 超时自动过期
  • ACK 状态机：received → executing → executed
curl · 发送一次回车
curl -X POST http://localhost:17890/api/v1/devices/HID-A1B2C3D4/commands \
  -H "Authorization: Bearer chk_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "protocol": "1.0",
    "request_id": "req-20260811-0001",
    "device_id": "HID-A1B2C3D4",
    "type": "keyboard",
    "action": "tap",
    "ttl_ms": 3000,
    "payload": { "key": "ENTER" }
  }'
ARCHITECTURE

三个组件，各司其职

整条控制链路都在你手里。设备控制不需要任何云端参与。

硬件

ESP32-S3 Smart HID

USB Keyboard + Mouse + Wi-Fi + MQTT + BLE 配网。执行命令、上报状态、维护 Device Identity 与 Boot ID。

本地核心

ControlHub

本地控制程序。HTTP API + 内嵌 MQTT Broker + 设备管理 + 命令引擎 + 动态配对 + 托盘常驻 + 本地 Web 控制台。

配网

BLE Toolkit+

微信小程序。BLE 搜索 Smart HID → 配网 → 设置 Wi-Fi → ControlHub 配对 → 诊断。开源个人小程序，无支付无会员。

PRINCIPLES

为什么这样设计

🏠

本地优先

实时控制永远不经过云。ControlHub 内嵌 Broker，断网也能用。云侧只持授权关系，不伪造设备在线状态。

🧩

全标准协议

HTTP、MQTT、USB HID 都是业界标准。任何能发 HTTP 请求的语言，一行代码即可驱动。

🛠️

开箱即用

下载即用，无账号、无订阅、无云端依赖——运行起来就是完全体，功能一个不少。

🔌

零侵入目标

目标电脑看到的是标准 USB 键鼠，无需驱动、无需控制端。适合自动化测试与受控环境联动。
