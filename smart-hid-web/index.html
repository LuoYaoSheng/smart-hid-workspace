CAPABILITIES

V1 键鼠能力

覆盖键鼠自动化的核心动作。V1 明确不做任意文本输入、宏脚本、Shell、远程桌面与截屏。

⌨️

键盘 Keyboard

  • tap — 单键敲击
  • hotkey — 组合键（如 Ctrl+C）
  • key_down / key_up — 按住 / 松开（带 lease）
🖱️

鼠标 Mouse

  • move — 相对移动
  • click — 单/双击
  • button_down / button_up — 按住 / 松开
  • wheel — 滚轮
🛡️

系统 System

  • release_all — 释放所有按住的键鼠
  • 会话级安全保障，异常时一键归零
🔐

可靠性

  • 每命令带 request_id，环形去重
  • ttl_ms 超时自动过期
  • ACK 状态机：received → executing → executed
curl · 发送一次回车
curl -X POST http://localhost:17890/api/v1/devices/HID-A1B2C3D4/commands \
  -H "Authorization: Bearer chk_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "protocol": "1.0",
    "request_id": "req-20260811-0001",
    "device_id": "HID-A1B2C3D4",
    "type": "keyboard",
    "action": "tap",
    "ttl_ms": 3000,
    "payload": { "key": "ENTER" }
  }'
ARCHITECTURE

五个组件，各司其职

实时控制链路与账号授权链路解耦。设备控制永远不需要云端参与。

硬件

USB Keyboard + Mouse + Wi-Fi + MQTT + BLE 配网。执行命令、上报状态、维护 Device Identity 与 Boot ID。

Windows 本地程序。HTTP API + 内嵌 MQTT Broker + 设备管理 + 命令引擎 + 试用 + License 离线验签 + 托盘 + 本地 Web 控制台。

PRINCIPLES

为什么这样设计

🏠

本地优先

实时控制永远不经过云。ControlHub 内嵌 Broker，断网也能用。云侧只持授权关系，不伪造设备在线状态。

⏱️

免费试用不阉割

键盘、鼠标、HTTP API、本地 MQTT 全部可用。仅按"累计有效控制时间"计费——无操作不消耗，配置/诊断免费。

🗝️

离线授权

License 云端签名、本地验签，主绑 ESP32 Device ID。激活后无需联网即可验证，稳定可靠。

🔌

零侵入目标

目标电脑看到的是标准 USB 键鼠，无需驱动、无需控制端。适合自动化测试与受控环境联动。
