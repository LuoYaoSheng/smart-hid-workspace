PROTOCOL · JSON SCHEMA

协议 Schema

Smart HID 设备与 ControlHub 之间三类消息的 JSON Schema（Draft 2020-12）。这是协议的事实源， 代码、文档、测试都以这里的字段定义为准。

传输层为 MQTT。Topic 与字段语义详见 HTTP API 文档与 系统架构。下方 Schema 描述消息体本身。

SmartHidCommand · 控制指令

控制端 → 设备。下发一次键鼠或系统动作。

  • type ∈ keyboard / mouse / system
  • ttl_ms 限定指令有效期（100–10000 ms），超时未执行则判 expired
  • target_boot_id 确保指令落到预期的设备启动实例，防止跨重启误命中
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "SmartHidCommand",
  "type": "object",
  "required": [
    "protocol",
    "request_id",
    "device_id",
    "target_boot_id",
    "type",
    "action",
    "ttl_ms",
    "payload"
  ],
  "properties": {
    "protocol": { "const": "1.0" },
    "request_id": { "type": "string", "minLength": 1, "maxLength": 96 },
    "device_id": { "type": "string", "pattern": "^HID-[A-Z0-9]{8}$" },
    "target_boot_id": { "type": "string" },
    "type": { "enum": [ "keyboard", "mouse", "system" ] },
    "action": { "type": "string" },
    "ttl_ms": { "type": "integer", "minimum": 100, "maximum": 10000 },
    "payload": { "type": "object" }
  },
  "additionalProperties": true
}

SmartHidAck · 执行回执

设备 → 控制端。回执指令的执行结果。

  • status 状态机：received → executing → executed；异常分支 rejected / expired / duplicate
  • code 为 0 表示成功，非 0 为错误码
  • execution_ms 设备端实测执行耗时，用于性能观测
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "SmartHidAck",
  "type": "object",
  "required": [ "protocol", "request_id", "device_id", "boot_id", "status", "code" ],
  "properties": {
    "protocol": { "const": "1.0" },
    "request_id": { "type": "string" },
    "device_id": { "type": "string" },
    "boot_id": { "type": "string" },
    "status": {
      "enum": [ "received", "executing", "executed", "rejected", "expired", "duplicate" ]
    },
    "code": { "type": "integer" },
    "execution_ms": { "type": "integer", "minimum": 0 }
  },
  "additionalProperties": true
}

SmartHidStatus · 设备状态

设备周期性广播的在线状态。

  • online 布尔，设备是否可达
  • boot_id 本次启动的唯一标识，与 Command 的 target_boot_id 对应
  • firmware / hardware 版本信息，便于运维与兼容性判断
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "SmartHidStatus",
  "type": "object",
  "required": [ "protocol", "device_id", "online" ],
  "properties": {
    "protocol": { "const": "1.0" },
    "device_id": { "type": "string" },
    "online": { "type": "boolean" },
    "boot_id": { "type": "string" },
    "firmware": { "type": "string" },
    "hardware": { "type": "string" }
  },
  "additionalProperties": true
}
